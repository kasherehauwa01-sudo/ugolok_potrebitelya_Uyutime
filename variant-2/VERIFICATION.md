- Три страницы ЕГРИП и изображение ИНН, отключённые кнопки на границах страниц.
- Скачивание обоих оригиналов, открытие в новой вкладке, закрытие кнопкой и Escape.
- Масштаб, сброс, предел 400%, перемещение увеличенной страницы с клавиатуры.
- Свайп и pinch-to-zoom через события касания Chromium при 390 px.
- Вход и выход из настоящего полноэкранного режима браузера.
- Цикл Tab / Shift+Tab внутри диалога, возвращение фокуса и восстановление прокрутки.
- Ошибка загрузки страницы документа: видимое сообщение и рабочая ссылка на оригинал.
- Открытие по `file://`, включая ЕГРИП и запасной способ копирования.
- HTTP-путь с префиксом `/repository/variant-2/`, имитирующий размещение в подпапке GitHub Pages.
- Статус работы в 08:59, 09:00, 19:59, 20:00 по Волгограду.
- Исходный сайт: загрузка, семь телефонов, открытие и закрытие документа.
- Отсутствие ошибок JavaScript и неуспешных запросов в основном прогоне.
