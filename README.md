# Уголок потребителя — второй вариант

Самостоятельный статический сайт на HTML5, CSS3 и Vanilla JavaScript. Сборка, npm, сервер, CDN и внешние библиотеки не нужны.

## Открыть локально

Откройте `index.html` в браузере двойным щелчком. Все ресурсы лежат внутри этой папки. Копирование предусматривает запасной способ для локального открытия; если браузер запрещает оба способа, интерфейс сообщает об ошибке, а не показывает ложное подтверждение.

## Размещение

Сайт размещён в корне репозитория. Откройте корневой index.html локально. Для GitHub Pages используйте ветку main и папку / (root). Все ресурсы подключены относительными путями, сборка не требуется. Прежний корневой README сохранён в README.initial.md. Исходный первый дизайн в отдельном репозитории Kupriyanova не изменён.

## Файлы

- `index.html` — семантическая страница, метаданные, навигация, разделы и диалог просмотра.
- `styles.css` — токены оформления и десять логических разделов CSS; мобильные стили базовые, расширения от 420, 700 и 1000 px.
- `script.js` — вывод реквизитов и телефонов, копирование, статус работы, навигация и просмотрщик.
- `config.js` — точная копия исходного файла фактических сведений.
- `assets/favicon.svg` — новый локальный графический знак.
- `assets/documents/ИНН Куприянова.jpg`, `ЕГРИП.pdf` — неизменённые оригиналы.
- `assets/documents/inn-thumb.jpg`, `egrip-thumb.jpg` — исходные миниатюры.
- `assets/documents/egrip-page-1.png` … `egrip-page-3.png` — все страницы исходного PDF, отрендеренные в 180 dpi без обрезки, для единого локального просмотрщика.
- `VERIFICATION.md` — результаты проверки и сведения об источнике.

## Концепция

Светлый информационный журнал: молочная бумага, графитовый текст, глубокий бордовый акцент, выразительный шрифт с засечками. Секция документов выделена тёмным фоном. Декоративная композиция собрана CSS и не загружает фотографии или шрифты из сети.

| Первый вариант | Второй вариант | Для чего |
| --- | --- | --- |
| Зелёный первый экран с крупным названием | Светлый редакционный заголовок с пояснением и компактными часами | Сразу объяснить назначение страницы |
| Пять плиток внутри первого экрана | Четыре самостоятельных навигационных пункта; правовые ссылки отдельным блоком | Упростить выбор на телефоне |
| Много раздельных карточек реквизитов | Единая карточка продавца с группами сведений | Создать целостную и спокойную структуру |
| Светлые карточки с большими сканами | Тёмная библиотека с компактными миниатюрами | Выделить документы в композиции |
| PDF зависит от встроенного просмотра браузера | Единое управление страницами, масштабом и жестами | Предсказуемая работа на мобильных устройствах и через file:// |

## Возможности

- ИНН, ОГРНИП, телефон, email и банковские реквизиты копируются; показывается toast.
- Сохранены юридический и почтовый адреса, дата регистрации, ОКВЭД, банковские сведения, семь служебных телефонов и обе ссылки на ГАРАНТ.
- Статус считается локально через `Intl.DateTimeFormat` в `Europe/Volgograd`, обновляется каждые 30 секунд и при возвращении во вкладку. График: 09:00–20:00, без выходных. После закрытия указан следующий день открытия.
- Просмотрщик занимает весь экран; на поддерживающих устройствах доступен Fullscreen API. В браузерах без API диалог всё равно занимает доступную область экрана.
- Масштаб 100–400%, кнопки «−»/«+», сброс нажатием на процент; двойной щелчок и жест двумя пальцами.
- Перелистывание кнопками, стрелками клавиатуры и горизонтальным свайпом. При увеличении один палец перемещает страницу.
- Оригиналы скачиваются или открываются в новой вкладке. При ошибке изображения есть ссылка на оригинал.
- Escape закрывает диалог; фокус удерживается внутри и возвращается к карточке. Стрелки перемещают увеличенный документ; `0` сбрасывает масштаб.
- Семантические разделы, skip-link, подписи кнопок, focus-visible, `prefers-reduced-motion`, безопасные отступы для мобильных устройств.

При замене PDF обновите также три PNG-страницы, миниатюру и количество страниц в конфигурации. При изменении графика синхронизируйте `config.js` и видимые статические подписи времени в `index.html`.
