# Уголок потребителя — ООО «Уютайм»

Статический сайт на HTML5, CSS3 и Vanilla JavaScript. Главная страница — `index.html` в корне репозитория. Сборка и внешние зависимости не нужны. Работает при открытии файла напрямую и на GitHub Pages из ветки main, папка / (root).

## Документы

В `assets/documents/` находятся неизменённые предоставленные `ИНН.pdf` и `ОГРН.JPG`, локальные миниатюры и PNG страницы PDF. Оба файла фактически содержат свидетельство о постановке на налоговый учёт, поэтому подписи соответствуют содержанию, а не только именам файлов. В сканах указано наименование ООО «Торговая компания «ВолгоРост»»; ИНН, КПП и ОГРН совпадают с картой ООО «Уютайм».

Сведения о сериях свидетельств в карте и сканах различаются. В интерфейсе записи из карты приведены отдельно с указанием источника. Имя руководителя «Кирьянова Ирина Юрьева» перенесено буквально из карты, без исправления предполагаемой опечатки.

Документы прежнего ИП удалены из текущей версии сайта. Они остаются в истории Git и в отдельном исходном проекте, который не изменялся. Карта партнёра используется как источник данных и отдельно на сайте не публикуется.

## Возможности

Копирование реквизитов, телефонные и почтовые ссылки, автоматический статус работы; просмотр оригиналов, масштаб 100–400%, pinch, перемещение, скачивание, полноэкранный режим и управление клавиатурой. Оба новых документа одностраничные: кнопки перелистывания корректно отключены. Для будущих многостраничных документов задайте массив `pageImages` в конфигурации и подготовьте изображения страниц.

Дизайн и адаптивная структура сохранены. Учитываются `prefers-reduced-motion`, safe-area и клавиатурный фокус.
